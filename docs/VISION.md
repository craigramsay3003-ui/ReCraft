# Vision

ReCraft aims to create artwork whose detail and procedural structure would be unrealistic to design by hand. It interprets an image rather than applying a cosmetic filter: source shapes, brightness, and edges become inputs to new visual systems.

The work should support distinctive one-off and limited-edition physical art. Recognisable source structure remains important, even when the interpretation becomes abstract; the source should still anchor the result emotionally and visually.

Procedural geometry is central to that ambition. Today's pixels may later become vectors, ribbons, depth fields, reliefs, or connected mesh geometry. Future manufacturable outputs could include STL and 3MF files suitable for physical validation and production.

Automatic analysis should guide rather than dictate meaning. The artist can
state what must be preserved or simplified using non-destructive importance
painting and assisted visual selections. Contour is the first style whose
procedural paths drive both 2D artwork and a watertight raised-ridge STL.
