WHAT HAS BEEN COMPLETED

- Created a working Python 3.11+ desktop prototype using PySide6.
- Added a src-based project structure under src/recraft.
- Added image selection, original-image display, transformed preview, PNG
  export, status messages, and error handling.
- Added dynamic style selection and parameter controls.
- Implemented three real procedural styles:
  - Contour: greyscale topographic isolines with adjustable density.
  - Halftone: brightness-based circles with adjustable cell size and contrast.
  - Fragment: edge-aware Delaunay triangulation that samples colours from the
    source image.
- Created an abstract ArtStyle interface with:
  - unique identifier
  - display name
  - description
  - parameter definitions and defaults
  - parameter validation
  - independent process(image, parameters) method
- Created a central style registry. The UI has no style-specific processing
  logic.
- Kept processing independent of PySide6 so it can later support batch tools,
  command-line processing, exporters, and mesh generation.
- Added recraft and python -m recraft application entry points.
- Added pyproject.toml, requirements.txt, a Python .gitignore, and an MIT

  style-extension, roadmap, status, and licence information.
- Added docs/VISION.md, docs/ROADMAP.md, docs/ARCHITECTURE.md, and
  examples/README.md.
- Added tests for image loading, invalid paths, registry metadata, duplicate

IMPORTANT CURRENT LIMITATIONS AND DECISIONS

- Version 0.1 generates 2D raster images only.
- There is no vector, SVG, mesh, STL, or 3MF export yet.
- Processing currently runs synchronously in the UI, so larger images may
  temporarily block interaction.
- Images are reduced to a maximum preview dimension of 1400 pixels before
  processing.
- Fragment uses SciPy Delaunay triangulation and OpenCV feature detection.
- OpenCV is supplied through opencv-python-headless because the desktop
  interface is provided by PySide6.
- Built-in style registration is explicit in create_default_registry. Adding a
  style requires adding its instance there, but no UI modification is required.
- This is an early experimental prototype and is not affiliated with HueForge
  or other existing software.
