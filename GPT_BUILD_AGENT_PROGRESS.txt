IMPORTANT CURRENT LIMITATIONS AND DECISIONS

- Version 0.1 generates 2D raster images only.
- There is no vector, SVG, mesh, STL, or 3MF export yet.
- Processing currently runs synchronously in the UI, so larger images may
  temporarily block interaction.
- Images are reduced to a maximum preview dimension of 1400 pixels before
  processing.
- Fragment uses SciPy Delaunay triangulation and OpenCV feature detection.
- OpenCV is supplied through opencv-python-headless because the desktop
  interface is provided by PySide6.
- Built-in style registration is explicit in create_default_registry. Adding a
  style requires adding its instance there, but no UI modification is required.
- This is an early experimental prototype and is not affiliated with HueForge
  or other existing software.

IMAGE PREPARATION UPDATE — 12 JULY 2026

Added a non-destructive preparation stage before every art style:

  imported image -> preparation -> prepared canvas -> style -> preview/export

The original full-resolution image remains unchanged in memory. Transformation
settings are stored independently, and every preview or export is regenerated
from the original source.

Features added:

- Fixed output/crop viewport with mouse-drag pan and mouse-wheel zoom.
- Numeric pan and zoom controls.
- Rotate left/right by 90 degrees without cumulative resampling.
- Horizontal and vertical flips.
- Reset to a valid centred source composition.
- Aspect lock and output width/height controls.
- Original, Square 1:1, Portrait 4:5, Portrait 2:3, Landscape 3:2, and
  Landscape 16:9 presets.
- Fit full image and Fill frame modes.
- Small interactive prepared/style previews, separate from full-resolution PNG
  rendering.
- Full export regenerates preparation and style output at configured dimensions;
  it never enlarges the rendered preview.
- Maximum output size is 8,000 pixels per dimension to reduce accidental memory
  exhaustion.

BACKGROUND RENDERING CHANGELOG — 12 JULY 2026

Resolved the known issue where large style previews and full-resolution exports
could freeze the application window.

Changes:

- Added src/recraft/ui/render_worker.py.
- Style preview processing now runs on a background QThread.
- Full-resolution preparation, style processing, and PNG writing now run on a
  background QThread.
- Each worker receives a snapshot of the original source, transformation state,
  selected style, and style parameters, preventing partial UI changes from
  affecting an in-progress render.
- Added an indeterminate progress indicator and useful status messages.
- Open, preparation, style, generate, and save controls are temporarily locked
  while a render runs, preventing conflicting jobs or settings changes.
- Worker errors are returned to the interface and shown to the user rather than
  being silently discarded.
- Closing the application is safely deferred while a background job is active,
  preventing a running render thread from being destroyed.
- Added tests/test_render_worker.py for preview results and full-resolution PNG
  writing.
- Updated README.md, docs/ARCHITECTURE.md, and docs/ROADMAP.md.

Updated limitation:

- ReCraft currently runs one render job at a time and does not yet provide a
  cancel button or percentage-based progress. The interface remains responsive
  and shows indeterminate progress while work completes.

RECRAFT ENGINE / IMAGE DNA CHANGELOG — 12 JULY 2026

Milestone: ReCraft now interprets a prepared image before procedural art runs.
The shared processing order is:

  imported image -> preparation -> ImageAnalysis -> style -> preview/export

Added package: src/recraft/engine

- analysis.py: orchestrates one analysis pass and bounds analysis maps to 1,200
  pixels on their longest side for predictable memory use.
- analysis_result.py: typed ImageAnalysis/Image DNA result, debug rendering,
  map resizing, and future user-mask attachment.
- edges.py: edges, gradient magnitude, local contrast, and texture.
- colour.py: deterministic k-means colour clusters.
- segmentation.py: spectral saliency, centre weighting, and general-purpose
  subject/background masks.
- faces.py: capability-based face detection and landmark extension points.
- importance.py: weighted automatic importance plus importance/additive/
  subtractive user-mask composition.

Reusable ImageAnalysis data now includes:

- greyscale and contrast-enhanced greyscale
- edge map and gradient magnitude
- colour cluster labels and centres
- texture and saliency maps
- face rectangles, soft face mask, and optional landmark collections
- subject and background masks
- image-centre weighting and local contrast
- automatic and combined editable importance maps

Importance combines edge/gradient strength, saliency, face confidence, local
contrast, object-boundary evidence, subject evidence, and centre distance. Its
float values are normalized to 0..1.

Style refactoring:

- ArtStyle.process now receives ImageAnalysis, not a raw Pillow image.
- Fragment uses importance-weighted feature/random points plus a regular base
  grid, limiting giant stretched polygons and adding detail to important areas.
- Contour smooths brightness before extracting bands, rejects tiny loops, and
  reinforces important edges.
- Halftone uses local brightness normalization and adaptive dot spacing/sizing;
  a minimum importance-aware dot prevents bright subjects from disappearing.
- Preview and export each analyse their prepared canvas once, then reuse that
  result within the selected style.

Developer UI:

- Added Artwork, Edge Map, Importance Map, Face Mask, Background Mask, Saliency,
  Colour Clusters, Texture, and Subject Mask preview options.
- Developer maps run in the existing responsive background worker.
- PNG export always produces selected artwork, never a developer map.

Tests:

- Added tests/test_engine.py.
- Updated style, prepared-pipeline, and worker tests for ImageAnalysis.
- 47 tests passed locally on Python 3.14.6.
- Tests cover every map, normalized ranges, independent source ownership,
  editable masks, all debug views, bounded large-image analysis, every style,
  preparation, background rendering, and full-resolution export.

Known limitations:

- OpenCV builds differ. Face detection runs when CascadeClassifier and its Haar
  data are available; otherwise Face Mask is safely zero and all general image
  cues continue to operate. The user's Python 3.14/OpenCV 5 wheel currently
  lacks that classic detector API.
- Face landmark estimation is represented in ImageAnalysis but requires a
  compatible external model that is not bundled; landmark collections are
  currently empty.
- Subject/background segmentation is a general saliency-based first version,
  not a semantic neural-network object detector.
- User importance/additive/subtractive masks were initially model-only; the
  subsequent changelog below records the completed painting tools.

USER IMPORTANCE + CONTOUR PHYSICAL ART CHANGELOG — 12 JULY 2026

Added a non-destructive importance override workflow and made Contour the first
path-native physical-art style.

Engine additions:

- user_importance.py: bounded source-space add/reduce masks, add/reduce/erase
  brushes, prepared-canvas inverse mapping, aligned rendering, weighting, and
  background suppression.
- colour_selection.py: Lab similarity, tolerance, feather, connected-only.
- region_selection.py: connected Lab visual-region growth with feather.

Contour and export additions:

- contour_geometry.py: ContourPath/ContourResult, smoothed brightness bands,
  length/tiny-loop/background filtering, importance retention, simplification,
  PNG rendering, and diagnostics.
- contour_mesh.py: millimetre raised ridges created from paths, flat base, side
  walls, printable-width validation, STL writing, and watertight validation.
- mesh_worker.py: background path generation, mesh creation, validation, export,
  errors, and summary signals.

UI workflow:

- Paint Add, Reduce, or Erase-to-automatic on the prepared image.
- Configure brush and automatic/user/background strengths; show/hide overlay or
  clear user edits.
- Pick a colour or connected region, preview, then Add, Reduce, or Cancel.
- Source-space masks remain aligned through preparation and export transforms.
- Added combined/user/selection/path developer diagnostics.
- Added Contour-only physical width, base, ridge height/width, border, and STL
  export controls with dimensions, mesh counts, watertightness, and path report.

Contour controls are Detail, Smoothing, Subject Emphasis, Background Reduction,
Line Weight, Simplification, Major Contours Only, and Invert. ContourResult paths
drive both PNG and STL; STL never re-detects lines from raster output.

Dependency: trimesh>=4.4.

Tests cover brushes, transformed mask alignment, colour/region selection,
normalization and strong overrides, path extraction/filtering/simplification,
background suppression, PNG rendering, physical dimensions, watertight STL,
minimum ridge width, invalid geometry, mesh worker export, and existing styles.
Final validation: 62 tests passed on Python 3.14.6, followed by compilation,
imports, off-screen UI, importance-aware PNG, true background STL with
watertightness confirmation, and timed startup smoke checks.

Known limitations:

- Visual selection is not semantic object detection.
- Importance editing has erase/clear but not undo/redo history yet.
- STL supports Contour raised ridges only; engraved channels are deferred.
- Ridges use a controlled grid representation of actual paths, so very fine
  curves are bounded by mesh resolution.
- No 3D viewport is included; inspect STL in a slicer.
- Face detection still depends on OpenCV detector availability.

FEATURE BRANCH — GUIDED CONTOUR RELIEF — 12 JULY 2026

Branch: feature/contour-workflow-relief, created from stable main 4a479ff and
pushed with upstream tracking. Do not merge without explicit instruction.

- Five-stage guided workflow with persistent canvas, Back/Next, preserved
  settings, collapsed Advanced controls, and separate diagnostics.
- Dependency-aware state: preparation invalidates all downstream work;
  importance/art invalidates paths/mesh; relief invalidates mesh; colours redraw
  materials without regenerating geometry.
- ContourPath carries peak importance, subject/background membership, and a
  smoothed per-point relief profile.
- Variable heights combine importance, subject/face evidence, contrast, and
  inverse background, then apply relief/background controls and safe mm bounds.
- Uniform-height compatibility, height smoothing, printable minimum, curve
  quality, physical height calculation, and developer orientation arrow.
- Independent Base/Contour colours, resettable pickers, shaded mesh preview,
  geometry-only STL explanation, and coloured 3MF material assignments.
- Orientation keeps X unchanged and inverts image Y into Cartesian +Y for the
  shared preview/STL/3MF mesh; this is not a camera workaround.
- Added Contour Height diagnostics and synthetic orientation/material tests.

See docs/CONTOUR_WORKFLOW.md for the staged workflow and calculations.
